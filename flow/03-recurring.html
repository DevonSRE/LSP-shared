Recurring billing — auto-renewal, retries and grace

A court switches on auto-renewal once, then a daily job charges its saved card. Paystack reports the outcome through a webhook, which is the only thing that can mark an automatic charge paid. Every box shows the endpoint it calls (base path /api/v1).

Things worth knowing

  • Turning on auto-renew never charges the court. It only reuses a card saved from an earlier payment, so a court has to pay once by hand first.
  • The immediate reply from Paystack's charge call is deliberately ignored. Only the signed webhook can mark the invoice paid, so one payment can never be applied by two code paths.
  • Retries stop after 3 failed attempts and the subscription stays in GRACE. That limit is a fixed value for now.
  • The dashed SUSPENDED box is not built yet. Nothing currently moves a subscription out of GRACE automatically, and nothing restricts case access. That's the Dunning work.
  • A network failure calling Paystack doesn't count as a failed attempt; the subscription is simply picked up again on the next daily run.
