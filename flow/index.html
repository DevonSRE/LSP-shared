Adding a flowchart

  • Copy any existing file in this folder, keep the same <head> and script block, and replace the diagram inside <pre class="mermaid">.
  • Give every stage box its endpoint, e.g. POST /platform/court-invoices. Use the same colours: blue Platform Admin, green Court Admin, purple Paystack/external, grey System, amber state, red rejection, dashed for not built.
  • Add a "Used by" row under the title with the Platform Admin and/or Court Admin badge, and the same badges on the index card.
  • Number files in order (06-…html) and add a card above.
  • Diagrams render with Mermaid loaded from a CDN, so open these with an internet connection.
