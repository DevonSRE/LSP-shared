Things worth knowing

  • Every step on this page is Platform Admin only.
  • Publish, archive and duplicate are one endpoint with a required action query parameter, not separate URLs.
  • Create and duplicate record who did it: the plan's created_by is a snapshot of that admin.
  • Publishing is a single call at any price. There is no second-admin approval.
  • Only a draft can be deleted. Once a plan has been published, it can only be archived, because courts and invoices may already point at it.
  • Editing a price never changes what a court has already been charged this cycle; the new price applies from its next renewal.
  • Archiving never moves anyone off a plan. A court already on an archived plan can still renew it; nobody else can newly pick it.
